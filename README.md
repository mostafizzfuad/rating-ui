An interactive and highly reusable **Rating UI Component** built from scratch using **React** and **Vite**. This project focuses on the core fundamentals of React, demonstrating how to manage state, handle user events, and build clean, composable UI elements.

## 🚀 Features

Based on the implemented modules, this project includes:

- **Interactive Rating Selection:** Users can select a rating value seamlessly utilizing React's `useState` hook and event handlers.
- **Dynamic UI & Conditional Rendering:** Styles and UI elements update dynamically based on the selected state (e.g., highlighting the chosen rating before submission).
- **Submission Modal:** Features a custom-built Modal component that appears upon rating submission, showing a "Thank You" state.
- **Advanced Component Composition:** Demonstrates the power of reusable components and passing data via the `children` prop for flexible layouts.
- **Fast & Optimized Build:** Bootstrapped with **Vite** for a lightning-fast development experience.

## 🛠️ Tech Stack

- **Framework:** React.js
- **Build Tool:** Vite
- **Syntax:** JSX (JavaScript XML)
- **Styling:** CSS
- **Core Concepts Used:** Hooks (`useState`), Props, Event Handling, Conditional Rendering, Component Composition.
